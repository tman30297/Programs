# Color Converter

Convert between color formats with visual preview.

## Usage

```bash
# From hex
python color_converter.py "#ff5500"

# From RGB
python color_converter.py "rgb(255, 85, 0)"

# From HSL
python color_converter.py "hsl(20, 100%, 50%)"

# From color name
python color_converter.py "coral"

# Interactive mode
python color_converter.py
```

## Supported Formats

- HEX (#ff5500, ff5500)
- RGB (rgb(255, 85, 0))
- HSL (hsl(20, 100%, 50%))
- Named colors (coral, navy, etc.)

Shows visual preview in terminal.
