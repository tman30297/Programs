## 1. 1-bit LLMs (Microsoft BitNet) ⭐ 34,067 stars

**What it is:** Official inference framework for 1-bit Large Language Models

**Why it matters:**
- Dramatically reduces LLM memory footprint (down to ~1.4GB for 70B model)
- Enables running large models on consumer hardware
- 10-100x less memory than full-precision models
- Key technology: BitLinear layers using ternary (-1, 0, +1) weights

**Use cases:**
- Edge deployment of LLMs
- Resource-constrained environments
- Cost-effective AI inference at scale

**Resources:**
- https://github.com/microsoft/BitNet
