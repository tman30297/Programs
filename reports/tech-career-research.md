- Most vendor-specific certs that expire quickly
- Entry-level certs if you have experience
- Certs without practical skills backing them up

1. Career change - certifications provide structure
2. Breaking into a new field - signals competency
3. Government/contractor work - often required
4. Self-taught developers - certs fill gaps

### When Experience Matters More
1. Already working in the field
2. Strong portfolio demonstrated
3. Senior roles (experience > certs)

### Portfolio Best Practices

1. **Quality over Quantity**
   - 3-5 strong projects > 20 trivial ones
   - Each project should demonstrate different skills

2. **Showcase Problem-Solving**
   - Include README with the problem, solution, and challenges
   - Document your decision-making process

3. **Make It Runnable**
   - Deploy to Vercel, Netlify, or Heroku
   - Include live demo links
   - Dockerize for reproducibility

4. **GitHub README Template**
   ```markdown
   # Project Name
   One-line description
   
   ## Tech Stack
   - Frontend: React, TypeScript
   - Backend: Node.js, PostgreSQL
   - Deployment: Docker, AWS
   
   ## Key Features
   - Feature 1
   - Feature 2
   
   ## What I Learned
   - Skill 1
   - Skill 2
   
   ## Run Locally
   npm install
   npm run dev
   ```

5. **Contribute to Open Source**
   - Good first issues on GitHub
   - Documentation improvements count
   - Bug fixes for experience

6. **Technical Blog**
   - Write about your projects
   - Explain technical decisions
   - Share lessons learned
